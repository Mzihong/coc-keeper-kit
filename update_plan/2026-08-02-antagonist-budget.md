## 已有素材:第三章给出的惯例数值

原样记录在此供讨论,**落盘时一律重写/重建,不照抄**(红线同教团计划)。

**技能点总预算带**(源文档称之为对邪教首领的标准建议):

| 预算 | 定位 |
|---|---|
| 300–400 | 弱,约等于一个平均水平的调查员 |
| 400–500 | 约等于一个强于平均的调查员 |
| 600–700 | 中等到强大 |
| 800–1000 | 非常强大 |

**技能点分配的四种方法:** ①标准池 `EDU×4 + INT×2 + 200`;②直接指定(快但易膨胀);
③抄现成原型改;④用预设数组。预设数组五组:

- A / B / C:6 个关键技能,总计 350 / 390 / 425 点
- D / E:12 个关键技能,总计各 700 点

**属性预设数组四组**(分配到 STR/CON/SIZ/DEX/INT/APP/POW/EDU):
A 平均 / B 高于平均 / C 强大 / D 长者(体能衰退、精神不减,高值给 POW/INT/EDU)。
配套两条护栏:属性 **80+ 会偏离创角的现实性与公平性**;施法者 **POW ≥ 70**。

**法术数量按资历:** 年轻 `1D4+1` / 标准 `1D6+1D4+2` / 成熟 `3D6+4` / 古老 `4D6+10`。

**SAN 惯例:** 邪教首领几乎都是 0;未走完堕落之路的可留 10–30。
普通邪教徒同样多为 0;守秘人想留救赎可能性时 10–35。
**明确规则:NPC 的 SAN 不掷,直接定。**

**技能上限的判断法**(比数字更有用的一条):技能值要与角色概念相称,且
"90% 步枪的物理学教授"既不合概念、**对调查员也过于致命**——上限由**致命性**倒推,
不由角色背景正推。

## Keeper 定案(2026-08-02 第二轮讨论)

与资深 KP 的第二轮讨论给出两条口径。**它们不是对上面素材的补充,而是改了本文的主机制**——
上面那张预算带表从"生成方法"降级为"审计上限"。

### 定案 A — 战斗难度按**敌人种类**对标,由弱到强

```
人类  <  怪物  <  古神眷族  <  古神
```

- 这是**跨种类**的粗标尺,同时覆盖 P4(人类侧)与 P9(怪物侧),
  等于给待讨论 2 里 `core/07` 那句"怪物不走本预算,走 X"一个**粗答案**:
  X 的第一层就是这条阶梯,**细节(档位区间、词条)仍归 P9**
- **遗留问题(见待讨论 7):** `core/07` 现有的 type 六类
  (human / beast / undead / mythos servitor / independent race / great old one)
  与这条四级阶梯**对不上**——beast、undead、independent race 落在哪一级没有说;
  且这条阶梯管的是**种类间**,种类**内部**的强弱仍由 threat 四档管,两套标尺如何咬合待定

### 定案 B — 邪教组织成员一律用**普通人类模板**

- **成员(人类敌人),不论职位高低,一律普通人类模板**——不按职位升级数值
- **教团首领 = 普通人类模板 + 法术 + 克苏鲁神话知识 + 高意志(高 POW)**
- 首领的技能**按其故事背景分配**对应技能
- **生成首领时须询问 Keeper:是否需要强化战斗方面能力**(默认不强化)

**对本文的影响(三处):**

1. **预算带不再是生成方法。** 首领不是"从 800–1000 那一档取数",而是
   "普通人类基线 + 上面四项增量"。第 26–33 行那张表**最多保留为审计上限**
   (用来查有没有写超),不作为生成入口 → 待讨论 3 已按此重写
2. **多了一个前置缺口:kit 里没有"普通人类模板"这个基线。** 定案 B 整个建立在它之上,
   它不存在则 B 无法执行 → 见待讨论 8
3. **多了一个流程要求:生成时要向 Keeper 提问。** 这是 spec 的交互点,不是数值内容 → 见待讨论 9

## 待讨论 3 — 预算带的定位(已随定案 B 改写)

**原问题**是"预算带的基准对不对";**定案 B 之后,先要问的是预算带还该不该当生成方法**。

定案 B 说邪教侧一律"普通人类模板 + 增量",不从预算带取数。那么预算带只剩两种可能定位:

| 定位 | 说明 | 代价 |
|---|---|---|
| **甲(倾向)· 审计上限** | 不作生成入口,只供 `core/11-review.md` 反查:某个反派的技能点总和是否越出其定位对应的带 | 需要一条"定位 → 带"的对照,但不需要精确 |
| 乙 · 完全删除 | 既然不用来生成,就别留一张会被误当模板的表 | 待讨论 5 的"致命性倒推"失去可量化的抓手,审计退回纯定性 |
| 丙 · 保留为**非邪教**人类反派的生成入口 | 邪教侧走定案 B,非邪教反派(黑帮、疯狂学者、竞争探险队)仍可按带生成 | 一套内容两种用法,`core/06` 要写清分叉,复杂度上升 |

**倾向甲。** 请 Keeper 确认;若选丙,要同时定"哪些人类反派算非邪教侧"。

**基准自验这条不因此作废**——只要预算带还留着(甲或丙),它的数字就仍须自算而非照抄:

- 7e 调查员职业技能点 = `EDU×4`(或职业指定的属性组合),兴趣点 = `INT×2`
- 以 EDU 70 / INT 70 计:280 + 140 = **420 点**(不含技能基础值)
- 那么"300–400 = 平均调查员"偏低一档,"400–500 = 强于平均"其实才是平均

→ 待办(定位选甲或丙才做):拿 `reference/rules/character-creation.md` 已有的车卡速查实算一遍,
**用算出来的数字重建预算带**,而不是抄源文档的。这条同时是红线上的正确做法。

## 待讨论 4 — 与人数缩放(P3 §7)的关系

§7 的 Scaling 侧栏按 party size 调**对手数量、线索冗余、SAN 总压力**。
单体强度预算与之是什么关系?

- 方案甲:正交。人数变化只调数量,单体强度锁定在剧本设定的那一档
- 方案乙:联动。给一条"每偏离基准人数 ±N 人,主要反派预算带升/降一档"的换算
- 方案丙:只给判断口径不给公式——"低于基准人数时优先降数量,数量已是 1 时才降强度"

倾向**丙**:公式化容易产生假精度,而 CoC 的致命性本就不靠精细平衡。

> **第二轮已趋定案:走丙。** 定案 B 里"生成首领时询问 Keeper 是否强化战斗能力"这条,
> 本身就是"给判断口径、由 Keeper 拍板"的做法——与丙同构,与乙(换算公式)相斥。
> 剩下要确认的只是:这个口径写在哪、与待讨论 9 的提问点合并还是分开。

## 待讨论 5 — 要不要带"致命性倒推"这条口径

上面记的那条(上限由对调查员的致命性倒推,不由角色背景正推)我认为是本章**最有价值的
一句**,比任何数组都通用。若采纳,它应该:

- 进 `core/11-review.md` 审计清单:"反派技能值是否可由单次成功检定造成不可逆后果?"
- 与 campaign `CLAUDE.md` 的 **lethality** 字段挂钩(该字段已存在于 intake)

这条会把本计划从"数值速查"升格为"审计能力",范围变大——**是否纳入本轮,请 Keeper 定**。

> **第二轮的冲突与调和。** 定案 B 说首领技能"**按故事背景分配**"(背景**正推**),
> 与本节这条"上限由致命性**倒推**、不由背景正推"表面相反。两者可并存,但必须写明分工:
>
> - **背景决定「选哪些技能」** —— 一个当过军医的首领有 Medicine、First Aid、Firearms,
>   一个学者首领没有
> - **致命性决定「能给到多高」** —— 同样是 Firearms,给 45% 还是 85%,由它对调查员
>   造成的后果倒推,不由"他当过兵所以应该很高"正推
>
> 不写明这条分工,两句话会互相取消:审计员既可以说"背景支持,合理",
> 也可以说"太致命,超标"。**若待讨论 5 决定纳入本轮,这段分工是必写内容。**

## 待讨论 7 — 种类阶梯与 `core/07` 现有分类如何咬合(定案 A 派生)

定案 A 的阶梯是 `人类 < 怪物 < 古神眷族 < 古神`。`core/07` 现有两套分类:

- **type 六类:** human / beast / undead / mythos servitor / independent race / great old one
- **threat 四档:** trivial / moderate / deadly / mythic(**只有名字没有区间**,见 P9)

对不上的地方:

- **对得上的:** 人类 ≈ human;古神眷族 ≈ mythos servitor;古神 ≈ great old one
- **对不上的:** **beast / undead / independent race** 三类落在阶梯哪一级没有说。
  尤其 **independent race**(深潜者、米·戈这类)——按"怪物"档偏低,按"眷族"档又不是眷族
- **两套标尺的分工:** 阶梯管**种类之间**,threat 四档管**种类之内**?
  若是,一只 `mythic` 的怪物是否可以强过一只 `trivial` 的眷族?**跨级重叠允不允许**,
  决定了这两套标尺是"嵌套"还是"独立"

**倾向:** 阶梯定**基线量级**,threat 四档在同种类内做 ±,**允许相邻级重叠、不允许跨两级**。
三个未归位的 type 各自挂到最近的一级并写明理由。**请 Keeper 定;细节归 P9 落地。**

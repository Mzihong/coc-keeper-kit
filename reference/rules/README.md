设任何检定难度、开任何理智损失之前先查这里,不要凭对 CoC 的印象写。入口在
`core/02-rules-reference.md`。

**"最后一句话"就在本目录。** `reference/sourcebooks/keeper-rulebook-7e-zh.md` 仍在版本库
里,但它已于 2026-08-06(P12)**退出查询链路**:它是对账底本,不是查不到时回落去硬读的
下一站。速查表答不出来的东西,应该被补进速查表,而不是绕过它。

## 体例(P12 定稿,2026-08-06)

1. **头部**一句话定位 + `> 来源:《守秘人规则书》第 N 章`。
2. **按书上小节顺序编号**,节标题中文 + 英文括注:`## 6.3 战技(Manoeuvres)`。
3. **规则条文写中文,术语英文括注,stat 记法保持英文**(`STR 60`、`1D6/2D10`、
   `Fighting (Brawl) 45%`)。这是对 kit 其余脚手架"英文正文"惯例的一次有意偏离——
   这几份是规则条文转录,不是 kit 原创内容。
4. **表格一律 markdown 表**,不保留 PDF 提取的错行形态。
5. **不收**页眉页脚、洛氏引文、叙事范例(哈维/农夫那类逐轮演示)。规则书里"某某范例"
   标题下若其实是**技能清单或数值参考表**,作为规则条文保留,但标题去掉"范例"二字。
6. **每节末尾留行号锚点** `<!-- 规则书 4421–4556 -->`。一节的内容若在原文里被表格
   隔断,锚点写成多段区间,不要用一个大区间把另有锚点的表格吞进去。

## 硬约定:速查表只能对着原文写

**不许凭印象提炼。** 没有行号锚点的段落视为未经核对,复评时按错误处理。首稿之后必须有
一次**逐节对账**,不是通读一遍就算。

这条是 P12 的诊断结论倒逼出来的:出过错的四份速查表(`chases.md` 整份机制错、
`sanity.md` 缺半章、旧 `tables/madness.md` 和书上不是同一张表、`combat.md` 大面积缺),
**全部诞生于规则书转录稿入库(2026-08-02 12:26)之前**——那时写速查表的会话手上根本没有
原文可对,写的是"对 CoC 的印象"。有原文之后写的、或事后回头对过账的,没有一份出错。

对账时**逐条核数值,不要只核结构**。2026-08-06 的复查在已声明"逐节对账通过"的章节里
仍查出三处错(`sanity.md` 疯狂发作时长写成定值 10 轮而非 1D10 轮、`combat.md` 全自动难度
阶梯把四组对应关系串成了七级链、`skill-checks.md` 对抗检定平手规则整条是编的)——
说明抽查几条关键数值不足以覆盖,**每一个具体数字和每一条阶梯关系都要单独回原文比一遍**。

## 自足性

速查表既然是终点,**里面就不该有指不到东西的引用**:

- 指别的速查表用**仓库相对路径 + 小节号**(`reference/rules/combat.md` §6.6),不要只写
  "表III"。
- **不要留规则书的页码/章节指路**("见规则书 105 页")。要么在仓库里找到对应物指过去,
  要么把那条规则本身写进来,要么明说本速查表不覆盖它。
- 数值确实可疑或原文残缺时,标 `<!-- 待核: … -->` 而不是猜。这些标记是欠账清单,
  不许静默填平。

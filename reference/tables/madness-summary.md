# madness-summary.md — 疯狂发作:概括症状(Bout of Madness, Summary)

> 来源:《守秘人规则书》第八章 8.3 疯狂的影响,表VIII(仅附录 16476–16513;正文无
> 对应重印)

单次理智检定损失 **5 点或以上**(且通过了那次 INT 检定,意识到自己见到了什么)时,
调查员立即陷入**疯狂发作**。概括症状用于发作发生在调查员**独处**、或**全体调查员
同时发作**时——守秘人可以快进直接描述结果,调查员在疯狂中迷失自身、脱离玩家控制
**1D10 小时**,本人不会记得这段时间的行为,只会在恢复后发现自己所处的陌生场景。
若发作发生在此刻的场景里、需要逐轮处理,改查 `madness-instant.md`(表VII)。掷出的
结果和当下剧情不搭就直接挑一条。

## 表VIII:疯狂发作 - 概括症状

| d10 | 症状 | 效果 |
|---|---|---|
| 1 | 失忆(Amnesia) | 在陌生地方回过神来,忘记自己是谁;记忆随时间缓慢恢复。 |
| 2 | 被窃(Robbed) | 毫发无损但被盗——携带的宝贵之物做幸运检定决定是否被盗,其余贵重品无需检定自动消失。 |
| 3 | 遍体鳞伤(Beaten) | 浑身拳痕瘀伤,HP 降到疯狂前一半(不构成重伤);伤从何来由守秘人决定,财物未被盗。 |
| 4 | 暴力倾向(Violence) | 陷入强烈的暴力与破坏欲;回过神来后做过什么可能明显、可能被记住也可能不;对象与后果(杀人或只是致伤)由守秘人决定。 |
| 5 | 极端信念(Extreme belief) | 查看背景中的思想信念,以极端疯狂的方式展示其一(如信教者被发现在地铁高声布道)。 |
| 6 | 重要之人(Significant person) | 不顾一切地接近背景中的重要之人,并按两者关系行动。 |
| 7 | 被收容(Institutionalized) | 在精神病院病房或警局牢房中回过神来,可能慢慢回想起被关押的经过。 |
| 8 | 逃避行为(Flee) | 清醒时发现自己已在很远的地方——迷失荒野,或坐在驶向远方的列车/长途汽车上。 |
| 9 | 恐惧(New phobia) | 患上新恐惧症:在 `phobias.md` 表IX **恐惧症状表**投 D100 决定,或由守秘人指定;开始不计代价避开恐惧源。 |
| 10 | 躁狂(New mania) | 患上新躁狂症:在 `manias.md` 表X **躁狂症状表**投 D100 决定,或由守秘人指定;发作期间完全沉浸于新躁狂,是否被旁人察觉由守秘人与玩家决定。 |

<!-- 规则书 16476–16513 -->

新获得的恐惧症/躁狂症要记在调查员卡上——它会**习惯化**(见 `reference/rules/sanity.md`
→ 8.5 习惯恐惧),挑最糟的时机让它再犯一次。

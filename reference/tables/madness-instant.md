# madness-instant.md — 疯狂发作:即时症状(Bout of Madness, Real-time)

> 来源:《守秘人规则书》第八章 8.3 疯狂的影响,表VII(正文 5154;附录重印 16450–16475,
> 内容一致)

单次理智检定损失 **5 点或以上**(且通过了那次 INT 检定,意识到自己见到了什么)时,
调查员立即陷入**疯狂发作**。即时症状用于发作发生在**此刻的场景里**时,持续 **1D10 轮**;
若发作跳到之后概括处理,改查 `madness-summary.md`(表VIII)。掷出的结果和当下剧情不搭
就直接挑一条。

## 表VII:疯狂发作 - 即时症状

| d10 | 症状 | 效果 |
|---|---|---|
| 1 | 失忆(Amnesia) | 只记得最后所在的安全地点,却没有任何来到这里的记忆。 |
| 2 | 假性残疾(Pseudo-disability) | 陷入心理性的失明、失聪或躯体缺失感。 |
| 3 | 暴力倾向(Violence) | 陷入六亲不认的暴力行为,对周围敌友无差别攻击。 |
| 4 | 偏执(Paranoia) | 陷入严重偏执妄想:所有人都想伤害他们、没有人可信任、正在被监视、遭到背叛、所见皆是诡计。 |
| 5 | 人际依赖(Attachment) | 因某些原因把他人误认为自己背景中的重要之人,并据两者关系行动。 |
| 6 | 昏厥(Faint) | 当场昏倒,需 1D10 轮才能苏醒。 |
| 7 | 逃避行为(Flee) | 用任何手段试图逃离当前位置,即使要开走唯一的交通工具并抛下同伴。 |
| 8 | 竭嘶底里(Hysteria) | 表现出大笑、哭泣、嘶吼、害怕等极端情绪。 |
| 9 | 恐惧(Phobia onset) | 投 D100(或由守秘人指定)从 `phobias.md` 表IX **恐惧症状表**选一个恐惧源;即使该恐惧源实际不存在,调查员也会在接下来的时间内认定它存在。 |
| 10 | 躁狂(Mania onset) | 投 D100(或由守秘人指定)从 `manias.md` 表X **躁狂症状表**选一个诱因,接下来的时间内调查员渴望沉溺其中。 |

<!-- 规则书 16450–16475 -->

新获得的恐惧症/躁狂症要记在调查员卡上——它会**习惯化**(见 `reference/rules/sanity.md`
→ 8.5 习惯恐惧),挑最糟的时机让它再犯一次。

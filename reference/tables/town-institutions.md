# town-institutions.md — 这个镇里有哪些机构

掷 **1d20**,一次填一条进这个镇(或这一区)的机构清单。**与 `locations.md` 分工不同**:
`locations.md` 掷 1 次定整个战役的舞台;本表掷 **N** 次填清单,N 随镇的规模走——2 区的
矿村掷得少,9 区的城掷得多,与文字地图卡「每区 3–5 个地点」是同一个量。见
`reference/craft/town-anatomy-zh.md` §一、§二。

**只收世俗机构。** 神话层(禁书、恐怖生物)不在这张表里——它该混进下面某一条掷出的
普通条目中,不单开分区,见 `town-anatomy-zh.md` §三。1–12 行是「各行各业与专业人员」
的子分类(实测占比最高的一类,细分成 12 个互不重叠的行当);13–20 行是其余八类机构,
各占一行。

| d20 | 机构/行当 |
|---|---|
| 1 | 法律与文书:一间律师事务所或公证处,手上有一份迟迟没人来签收的文件 |
| 2 | 医疗与心理:一位私人执业的医生或心理分析师,病历柜锁着,连护士都进不去 |
| 3 | 治安与阴影:一名警员或私家侦探,手头有一桩多年未结的旧案,逢人就想再提 |
| 4 | 学术与文墨:一位地方史学者或记者,书房里堆着没人愿意资助出版的手稿 |
| 5 | 传统匠人:一间铁匠铺或钟表修理铺,老板接的私活比明面上的生意还多 |
| 6 | 店铺与经纪:一家杂货店或旧货经纪,账本上有一笔总也对不上的进货 |
| 7 | 技术与建筑:一位建筑师或勘测员,图纸上标出一块镇上没人愿意提起的地 |
| 8 | 艺文与表演:一位画家或雕塑家,最近的作品题材让委托人不太自在 |
| 9 | 另类与边缘知识:一位占星师或灵媒,常客名单比教堂的礼拜名册还长 |
| 10 | 公职与行政:一位镇政府雇员,批文件的手很松,只要对方是老相识 |
| 11 | 日常服务:一位理发师或药剂师,柜台后面的闲话比镇报纸更新得快 |
| 12 | 运输与劳力:一位马车夫或码头工头,深更半夜总在替人跑一趟说不清的差事 |
| 13 | 餐饮娱乐:一家餐馆或台球厅,打烊后灯还亮着,没人承认自己留在里面 |
| 14 | 旅馆公寓:一栋公寓楼,长住的房客彼此从不打招呼,却在同一天搬进来 |
| 15 | 教堂:一间小教堂或聚会所,信众比登记簿上的名字少了一半 |
| 16 | 俱乐部与组织:一个只接受邀请入会的社团,会费不高,但没人愿意退会 |
| 17 | 工厂与商业设施:一座半停工的作坊或仓库,夜班的灯还亮着 |
| 18 | 杂项:一处施工工地或废弃地基,进度比合理工期慢了不止一倍 |
| 19 | 殡葬墓地:一间殡仪馆或老墓园,记录本上有几页被撕掉了 |
| 20 | 医疗机构:一家小型疗养院或诊所,床位常年满员,却几乎没人见过病人出院 |

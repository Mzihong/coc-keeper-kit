# 图示惯例 — 简体中文

kit 里**所有关系类图示**的画法惯例,供 `core/03-build-world.md`(§二 势力/关系图、
§四 区域关系图)、`core/04-design-scenario.md`(§三 场景网)、`templates/cult.md`
(§二)共用。**一律用 mermaid**,不用 ASCII 拼图、不用生成位图。

**为什么是 mermaid:** GitHub 与 Artifact 原生渲染,三条链路(Claude Code / Gemini CLI /
codex)都会写,改一个节点的 diff 只有那一行——生成位图或手写精细 SVG 三条都做不到。

建筑内部与野外站点的**平面图**不在本文范围,那是 `scripts/render-map.py` 的活。

---

## 一、通用规则(每张图都要守)

1. **每条连线必须带标签,写连接二者的「东西」是什么。** 不是"敌对"、"认识",而是
   **可调查的具体形态**:「欠 800 元赌债」「共用南码头三号仓库」「同一个接生婆」。
   图上真正可执行的是连线,孤立的圈没有用;**没标签的线等于没画**。
2. **节点 5–12 个。** 少于 3 个别画图,一句话说得更快;超过 12 个说明该拆两张,
   或者该先分层再画。
3. **节点 ID 用英文短码,显示名用战役的输出语言。** mermaid 的 ID 不能带空格和多数标点,
   写 `harbormaster["李海生 · 港务长"]` 而不是直接把中文当 ID。
4. **每张图上面配一句话:这张图回答什么问题。** 答不上来的图删掉。
5. **剧透分版。** KEEPER ONLY 的节点与连线不进玩家版。要给玩家看就另画一张,
   别指望在同一张图上"让他们别看那条线"。
6. **图不替代正文。** 图给的是结构,细节(NPC 想要什么、线索长什么样)留在各自的文件里,
   用相对链接指过去。

## 二、势力 / 关系图 —— `core/03-build-world.md`(faction)、`templates/cult.md`

回答的问题:**谁和谁绑在一起,调查员能从哪一头拆。**

- **节点不要只放人。** 人 / 组织 / 地点 / 物件混排——一间仓库、一本账簿常常比一个 NPC
  更适合当枢纽。
- 有方向的关系(钱流、命令链、供货)用 `-->`;纯关联用 `---`。
- 层级用 `subgraph` 表达(外围成员 / 核心圈 / 首领),别用节点颜色——颜色在纯文本 diff
  里读不出来。
- **至少留一条"外人也能看见"的连线**,那是调查员的入口。全是秘密连线的图等于没有入口。

```mermaid
graph LR
  subgraph outer[外围]
    docker["陈阿水 · 码头工"]
  end
  subgraph core[核心圈]
    priest["林道长 · 主祭"]
  end
  ledger["南码头三号仓库账簿"]
  docker -->|"每月初七卸货,不问货是什么"| ledger
  ledger -->|"签收人一栏永远是同一个假名"| priest
```

## 三、场景网 —— `core/04-design-scenario.md`

回答的问题:**从任一场景出发,下一步能去哪,靠哪条线索过去。**

- 节点 = 场景;边标签 = **通往下一场景所依赖的那条线索**,不是"然后"。
- **三线索规则可视化:** 每个"必须到达"的场景至少有 **3 条入边**。入边少于 3 条的节点
  就是卡点,画完先数一遍——这比事后审查便宜。
- **死路要画出来并标注**(`-.->|"死路:只排除嫌疑,不给新方向"|`),让 KP 一眼看见哪里会
  空转;不画反而显得处处通。

## 四、区域关系图 —— `core/03-build-world.md`(region / town)

回答的问题:**这些地方怎么互相到达,要多久。**

- 边标签写 **怎么过去 + 花多久**:「步行 20 分钟」「渡船,每日两班」「涨潮时断路」。
  时间和阻断条件是跑团时真正会被问到的东西。
- 这也是**跑不了 `scripts/render-map.py` 时**(没有 Python、或 Keeper 不想为一张草图开一次
  渲染)的地图替代品:出这张图 + 文字地图卡,不要承诺一张画不出来的平面图。

## 五、不要画图的情况

| 情况 | 改用 |
|---|---|
| 只有 2–3 个节点 | 一句话写清 |
| 建筑内部布局、野外站点 | 平面图 → `scripts/render-map.py` |
| 时间线、事件钟 | 表格(`core/05-event-clock.md` 已有体例) |
| 数值对比 | 表格 |

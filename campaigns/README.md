# campaigns/

One folder per game you run. To start a new campaign:

1. **Copy the template:** `_template-campaign/` → `<your-campaign-slug>/`.
2. **Fill `CLAUDE.md`** in the new folder — era, tone, premise, content lines, canon. This is
   what the skills read to match voice and period.
3. **Generate into the subfolders** (`world/`, `npcs/`, `scenes/`, `puzzles/`, `handouts/`,
   `sessions/`) using the skills. Cross-link freely.

Keep campaign-specific material here. Anything reusable across games (a generic monster, a
Mythos tome, a random table) belongs in the root `reference/` instead.

`_template-campaign/` is the skeleton — don't run a game out of it; copy it.

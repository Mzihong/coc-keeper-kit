# 北戴河海濱

> 過季的避暑地。夏天三千人，冬天二十七人。

## 身分與氣味

自光緒年間開埠以來，北戴河海濱就是外國人的夏天：領事、海關幫辦、開灤煤礦的工程師、教會的
傳教士，在東經路兩側蓋了兩百多幢別墅。京奉鐵路到北戴河站，再換一段輕便鐵道進海濱。

冬天不是這樣。十月封園，五月開海。中間七個月，海濱交給看房人——多數是本地人，一人管三到八
幢空屋，燒炕、掃雪、防賊、防潮。他們一個冬天可能只跟兩三個人說話。

- **聲音**：風穿過釘死的百葉窗；空屋裡的地板在夜裡自己響（熱脹冷縮，看房人都習慣了）。
- **氣味**：煤煙、凍住的海腥、別墅裡經年不散的樟腦。
- **景象**：兩百幢屋子，只有七八個窗口在晚上有燈。燈的位置每晚都一樣——直到不一樣。

## 幾個地方

| 地方 | 有什麼 | 可互動的細節 |
|---|---|---|
| **東經路別墅區** | 兩百餘幢空屋，看房人分片管理 | 每幢門上掛著木牌，寫著業主姓名與「本冬看房人」；有三塊牌子的名字在十二月被重寫過 |
| **蓮花石** | 海邊一組礁石，退大潮時露出一道石縫 | 縫裡有人放過東西：一隻搪瓷杯、一雙童鞋、一副眼鏡，都乾淨，都不舊 |
| **鴿子窩** | 觀日出的高崖 | 崖下沙上常年有腳印通向海，沒有回來的 |
| **海濱郵政代辦所** | 冬天每週開兩天 | 掛號簿上，去年十一月起有人每週寄同一個地址的信，寄件人是本地看房人，但他不識字 |
| **金山嘴漁村** | 十一戶漁家，與海濱互不往來 | 漁民冬天不下蓮花石那片水域，說法是「有暗流」；他們的孩子被禁止靠近 |
| **輕便鐵道車房** | 冬季停駛，一輛手搖平車可用 | 車房裡的煤油燈，油每週都少，沒人承認用過 |

## 幾個人

- **李樹春**——看房人的頭，管東經路北段十一幢。見 `../npcs/li-shuchun.md`。
- **費太太（Mrs. Fee）**——挪威籍寡婦，唯一整年住在海濱的外國人。見 `../npcs/mrs-fee.md`。
- **趙德海**——金山嘴漁村的老大，決定漁船去哪不去哪。話極少，禁令極硬。
- **小圈子**：郵政代辦員（天津派來，冬天當值，恨這份差）、一名住在山海關的稽查員（每月來一次）。

## 傳聞

| 傳聞 | 真假 |
|---|---|
| 「蓮花石那邊有暗流，冬天別下水。」 | **真**——但不是暗流的緣故 |
| 「看房人一冬下來都會有點怪，關太久了。」 | **半真**——今年的怪法不一樣 |
| 「去年冬天凍死過一個看房人，家裡人領回去了。」 | **假**——沒有人領走任何東西 |
| 「別墅裡有俄國人的金子，藏在地板下。」 | **假**（漂亮的紅鯡魚，會耗掉一整場） |
| 「費太太的先生沒有死，只是不出門。」 | **真**，但不是她以為的那個意思 |

## 底下那件事

> **KEEPER ONLY**
> 蓮花石底下有一個石室，不是人造的。裡面現在躺著九個人：七個看房人、一個郵政臨時工、一個
> 1924 年打仗時逃過來的兵。全部活著，體溫低，不老，不醒。
>
> 那東西沒有名字，也不需要祭拜。它的規則簡單到可怕：**看見一個人長期獨處，就當作損壞，然後
> 修補**。修補的方式是做一個同伴出來——溫和、記憶完整、會做本體會做的事，只是體溫偏低、不
> 出汗、在強光下影子邊緣不對。本體被收起來保存，因為它不明白人會死，也不明白「原件」的概念。
>
> 複製品**自己不知道自己是複製品**。他們沒有惡意，他們甚至比原件好相處。這是全劇的殘忍所在：
> 沒有可以殺的怪物，只有九個很好的人，和九個睡著的人，而你必須決定怎麼辦。
>
> 詳見 `event-clock.md`。

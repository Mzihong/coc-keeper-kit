## Introduction

*For a Keeper opening this file cold, possibly at a different table than the one it was
written for.*

- **Era & locale:** `dark-ages`（欧洲黑暗时代基调，架空谷地，不挂靠真实地名信仰）——一座被
  森林围死的山谷村落 + 谷外一片旧世界废墟。**这个设定可以直接照搬**：没有任何真实历史或

## Worldview

### 前提，一句话

韦尔加谷是山坳里的一座村子，四面被长林围死；石哨立在北脊上，四百一十二年来永远有两人
轮班驻守。一位调查员刚继承了一处树线之外、自己从不知道存在的房产，附带条件——这把当值
的那一对推出了树线。谷外是不生原：一片什么都不长的地方，立着灰砂石建筑，剜得出骨铁，
刻满没人认得的先民纹。石哨最近看见的东西变了：不是从山里出来的，是从**更远的地方搬过来
的**——它原来待的地方，已经待不下去了。

四处地点，脚程按此顺序累加，谁也绕不过谁：

| 地点 | 表层 | KEEPER ONLY 里层 |
|---|---|---|
| **韦尔加谷** — 常驻据点，260 人，分谷心/坡上/林缘三片 | 石屋挤在山坳里，谷心一口井四百年没干过 | 没有独立神话威胁——谷里的"不对劲"是史料被抹平留下的物证（灯、丧葬簿撕页），不是谷里自己招来的东西 |
| **石哨** — 北脊上的守望塔，两层 | 灰砂石方塔，先民纹满墙，不灭的火，山在念 | 旧世界**监测中继站**残骸；双人轮值是它原本的人事编制，不是民俗；双手廊两端同步手柄是**物理约束**（伺服天线的人力备用校位装置），不是仪式 |
| **不生原** — 遗迹带，寸草不生 | 灰白碎石地，太笔直的灰砂石墩子，径痕贯穿全境 | 混凝土地基+输电走廊遗址；**两批遗物年代相差近五百年却被当成一批**（断阵/卧城约1200年前，新垒约500–700年前，新垒直接拆用断阵旧构件）；径痕是**过路痕迹**，不是巢穴 |
| **守井宅** — 继承来的宅邸，卡在石哨与不生原之间 | 矮房子，门闩崭新，地窖一道笔直石阶通向黑暗 | 靠一具手动排水阀轮维持地基干燥（这正是它没塌的真正原因）；条件——满月夜必须到场且不能独自前往——是**纯粹的土木问题**被谷里当成了祖训 |

### Time structure

谷里的历法从「第一个守望年」起算，之前的一切统称模糊的「先民时候」——这不是记录丢了，是
谷里的记年方式**从没有能力分出**「一千年前」和「四百年前」的区别。

| 谷里怎么算 | 守秘人手上的真实年表 | 谷里知道吗 |
|---|---|---|
| 「先民时候」（无年份） | 崩溃发生在约 **1200 年前**；之后约 **800 年**是完全的空白（有零星物证，连不成一条线） | 不知道——一个词兜住了两段完全不同长度的时间 |
| 第 1 守望年起 | **412 年前**，一队外来者（口传里的「凯佛伦」）重新点起半塌的石哨，定下两人轮值的规矩 | 知道，这是他们记录的起点 |
| 第 412 守望年（现在） | 战役开局 | 知道 |

**这条时间结构会反复咬人**：调查员会把 1200 年前和 400 年前的遗物当成同一个年代——那不是
玩家的失误，是这个世界本身的认知缺陷。最锋利的落点：不生原的「新垒」是拆「断阵」的石头
砌成的，证明八百年空白期里确实有人来过、也懂得拆解先民的东西。

### Factions & tension（世俗，不需要邪教）

- **沃辛宗族 Vossin** vs **科瓦宗族 Kova**（都住坡上）——为石哨排班表结下尚未爆发的世仇；
  「轮遍全谷」是名义，实际出人的几乎全是坡上人家，这道缝迟早要吵开。
- **骨铁贸易的三方分账**——骨队（担风险最大）、锻骨匠（吃手艺门道）、议家会（握出树线
  许可+抽贡额）三方都觉得自己分得少；议家会最近悄悄把贡额从一成半提到两成，没解释去向
  （真相：加派给了石哨，但议家会自己也说不清"为什么突然要加派"）。

### The threat（本战役最大的问号，intake 阶段刻意不封死）

**Category：** 独立存在——迁徙而来的东西，**无人类反派，无邪教**。它在这里不是因为被召唤
或崇拜，而是因为它原来待的地方待不下去了；它对韦尔加谷没有意图，谷地只是它路线上的一处
地形。具体形态、它逃离的是什么、石哨中继站是否仍在向它（或别的什么）传输——**两个问号，
见文末「留白问号」，故意留给下一步设计**。

## Translation glossary

> **战役硬规约：** 任何与遗迹沾边的地点/物件/声音，表层给玩家的描述里，**不许出现里层的
> 任何一个词**。这张表是双向词典——写新场景时照此扩写，不要另创译法。

| 里层（真实） | 表层（谷里的说法） |
|---|---|
| 混凝土 | **灰砂石** —— 一种没人会造、也没人见过谁造的石头；太平整，边太直 |
| 钢筋 / 钢梁 | **骨铁** —— 硬度远超剑，锻不动、凿不断，只能从灰砂石里剜出来 |
| 玻璃 | **凝水** —— 冻住的水，不化，割手 |
| 显示器 / 屏幕 | **死镜** —— 照不出人的镜子 |
| 电缆 / 线束 | **石中筋** —— 灰砂石断口里露出的、裹着软皮的细骨铁 |
| 塑料 | **不腐皮** —— 埋多久都不烂，烧起来发臭 |
| 印刷文字 / 标识牌 | **先民纹** —— 被当成符咒或装饰；谷里没人知道那是字 |
| 指示灯 / 应急灯 | **不灭的火** —— 不烫，不用油，风吹不动 |
| 机器运转声 / 蜂鸣 | **山在念** —— 一种低而稳的声音；谷里认为是山自己在说话 |
| 楼梯间 / 走廊 | **直洞** —— 太直、太规整，不像人挖的 |

谷里的纪年单位「**守望年**」（从第一个守望年起算，现在是第 412 年）、货币单位「**便士**」
（借用的记账老词，谷里几十年没人真见过硬币）也算这套体系的一部分，但不是里/表转译——
它们本身就是这个世界原生的说法。

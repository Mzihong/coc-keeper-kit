## Worldview

### 前提，一句话

韦尔加谷是山坳里的一座村子，四面被长林围死；北脊上立着一栋叫**守井宅**的老屋，四百一十二
年来每逢满月永远有两人前往。一位调查员刚继承了这处房产——自己从没听过这个名字，附带条件
把当值的那一对推出了树线。谷外是不生原：一整座 1999 年停摆的小镇废墟，什么都不长，立着灰
砂石建筑，剜得出骨铁，刻满没人认得的先民纹。北脊那头最近感觉到的东西变了：不是从山里出来
的，是从**更远的地方搬过来的**——它原来待的地方，已经待不下去了。

| 地点 | 表层 | KEEPER ONLY 里层 |
|---|---|---|
| **韦尔加谷** — 常驻据点，260 人，分谷心/坡上/林缘三片，含教堂 | 石屋挤在山坳里，谷心一口井四百年没干过，钟楼探出屋顶 | 没有独立神话威胁——谷里的"不对劲"是四百一十二年集体没起疑（五层理由）+ 史料被抹平留下的物证（灯、丧葬簿撕页），不是谷里自己招来的东西 |
| **守井宅** — 北脊上继承来的宅邸，**本战役威胁的法阵锚点** | 木板墙、铁皮顶的独栋房子，样式和谷里任何一间都不像，地窖一道笔直石阶通向黑暗 | 靠一具手动排水阀轮维持地基与阵的读数；代价是**意志（POW）**——涓滴（每次守夜两人各失 1D3 点）→ 整份（阵吃紧时抽走一人全部），三级递进 = doom track |
| **不生原** — 遗迹带，寸草不生，1999 年小镇废墟核心区 | 灰白碎石地，太笔直的灰砂石墩子与木杆，径痕贯穿全境 | 一整座小镇的浇筑地基+街道遗址；**两批遗物年代相差近五百年却被当成一批**（列桩/卧城约1200年前，新垒约500–700年前，新垒直接拆用卧城旧墙基）；径痕是**过路痕迹**，不是巢穴 |

### Time structure

谷里的历法从「第一个守望年」起算，之前的一切统称模糊的「先民时候」——这不是记录丢了，是
谷里的记年方式**从没有能力分出**「一千年前」和「四百年前」的区别。

| 谷里怎么算 | 守秘人手上的真实年表 | 谷里知道吗 |
|---|---|---|
| 「先民时候」（无年份） | 崩溃发生于**公元 1999 年**，约 **1200 年前**；之后约 **800 年**是完全的空白（一个遍布世界的修会点起的初始意志撑了这么久，才开始衰） | 不知道——一个词兜住了两段完全不同长度的时间 |
| 第 1 守望年起 | **412 年前**（约公元 2790 年），凯佛伦一队（大概率是那个修会末代还在行走的人）重新压实了守井宅的排水轮，定下满月两人同去的规矩 | 知道，这是他们记录的起点 |
| 第 412 守望年（现在） | 战役开局（约公元 3200 年） | 知道 |

**这条时间结构会反复咬人**：调查员会把 1200 年前和 400 年前的遗物当成同一个年代——那不是
玩家的失误，是这个世界本身的认知缺陷。最锋利的落点：不生原的「新垒」是拆「卧城」墙基
砌成的，证明八百年空白期里确实有人来过、也懂得拆解先民的东西。

### Factions & tension（世俗，不需要邪教）

- **沃辛宗族 Vossin** vs **科瓦宗族 Kova**（都住坡上）——为守井宅满月排班表结下尚未爆发的
  世仇；「轮遍全谷」是名义，实际出人的几乎全是坡上人家，这道缝迟早要吵开。真正的锋刃：
  沃辛几代人争着多认轮次，其实是在争着被抽干；科瓦青壮折损得多，想让别家多认一轮，却因为
  说出理由等于渎神而拿不出台面上的说法。
- **骨铁贸易的三方分账**——骨队（担风险最大）、锻骨匠（吃手艺门道）、议家会（握出树线
  许可+抽贡额）三方都觉得自己分得少；议家会最近悄悄把贡额从一成半提到两成，没解释去向
  （真相：加派给了守井宅的当值物资，但议家会自己也说不清"为什么突然要加派"）。

### The threat

**Category：** 独立存在——迁徙而来的东西，**无人类反派，无邪教**。它在这里不是因为被召唤
或崇拜，而是因为它原来待的地方待不下去了；它对韦尔加谷没有意图，谷地只是它路线上的一处
地形。

> **KEEPER ONLY —— 把它赶出老家的是什么，已经定死了：飞天水螅**
> （`reference/sourcebooks/malleus-monstrorum-zh.md:1536`，SAN 1d3/1d20，独立、不服侍任何
> 神格）。1999 年之前旧世界挖穿了一处封印，水螅从底下出来，把住在更深处的那样东西顶到了
> 地面——它从此开始走。**水螅永远不上场**：它只作为"为什么有个巨大的东西在走路"的答案存在，
> 不进任何一场戏。因果链完整版（修会、几百道阵、意志代价）见 `CLAUDE.md` → Canon so far。

**仍然敞着的三个问号**见文末「留白问号」——**注意那里问的不再是"它是什么"**，而是它现在
到哪了、代价谁来付、外面还剩几道阵。

## Translation glossary

> **战役硬规约：** 任何与遗迹沾边的地点/物件/声音，表层给玩家的描述里，**不许出现里层的
> 任何一个词**。这张表是双向词典——写新场景时照此扩写，不要另创译法。**教会体系的词汇
> （神父、什一税、圣髑、礼拜……）不走这套转译，直接用真实词。**

| 里层（真实） | 表层（谷里的说法） |
|---|---|
| 混凝土 | **灰砂石** —— 一种没人会造、也没人见过谁造的石头；太平整，边太直 |
| 钢筋 / 钢梁 | **骨铁** —— 硬度远超剑，锻不动、凿不断，只能从灰砂石里剜出来 |
| 玻璃 | **凝水** —— 冻住的水，不化，割手 |
| 显示器 / 屏幕 | **死镜** —— 照不出人的镜子 |
| 电缆 / 线束 | **石中筋** —— 灰砂石断口里露出的、裹着软皮的细骨铁 |
| 塑料 | **不腐皮** —— 埋多久都不烂，烧起来发臭 |
| 印刷文字 / 标识牌 | **先民纹** —— 被当成符咒或装饰；谷里没人知道那是字 |
| 电线杆 | **列桩** —— 一排排间距分毫不差的木杆或灰砂石杆，桩顶串着石中筋 |
| 沥青路面 | **黑石道** —— 又黑又软的石头，晒久了发粘 |
| 汽车 | **铁兽** —— 有轮子的铁壳子，肚子里能坐人，早已不动 |
| 指示灯 / 应急灯 | **不灭的火** —— 不烫，不用油，风吹不动 |
| 机器运转声 / 蜂鸣 | **山在念** —— 一种低而稳的声音；谷里认为是山自己在说话 |
| 楼梯间 / 走廊 / 地下室 | **直洞** —— 太直、太规整，不像人挖的 |

谷里的纪年单位「**守望年**」（从第一个守望年起算，现在是第 412 年）、货币单位「**便士**」
（借用的记账老词，谷里几十年没人真见过硬币）也算这套体系的一部分，但不是里/表转译——
它们本身就是这个世界原生的说法。
